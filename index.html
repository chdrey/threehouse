The studio

A treehouse for small worlds.

Threehouse is a one-person studio making small, handcrafted 3D worlds for the web. Like a treehouse, it's a place you climb up to, a bit hidden, a bit magical, and always growing.

The name is a nod to three.js, the open-source 3D engine every world here is built on.
